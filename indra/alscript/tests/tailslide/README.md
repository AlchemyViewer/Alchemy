# Tailslide's test scripts

The LSL scripts from Tailslide's `tests/scripts` (v1.5.12), under its MIT
license (LICENSE here), which the LSL to SLua assistant's tests run through
the converter for their breadth of LSL's corners: every one Tailslide takes
must convert and check clean as SLua, and each one it refuses -- listed in
`allsltoslua_test.cpp` -- must stay refused. Tailslide's expected outputs are
not needed and not copied. Copied again, as they are, when the port moves to
a Tailslide with new ones.
